# Jayjay's Portfolio

This repository will become my personal portfolio website.

## Goals

- Showcase projects I build.
- Explain what I learned from each project.
- Practice HTML, CSS, and Git.

## About This Project
I built and published a portfolio webpage using HTML, CSS, and GitHub Pages. HTML provides the page’s structure, while CSS controls its appearance, including colors, spacing, and layout. GitHub Pages hosts the website so others can visit it online.

Git helped me keep track of changes to my webpage by saving them as commits. I pushed those commits to GitHub to update the repository and published website.
